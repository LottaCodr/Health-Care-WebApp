# Hospital EMR - Operations Guide for Staff

**For Hospital Staff (Non-Technical Users)**

---

## 👋 Welcome!

This guide explains how to use the Hospital EMR system. Each staff member sees different screens based on their role.

---

## 🔐 Logging In

1. Go to: **https://your-hospital-domain.com**
2. Enter your **Email** and **Password**
3. Click **Login**
4. You should see your **Role Dashboard**

**If login fails:**
- Check your email is correct
- Check CAPS LOCK is off
- Wait 30 seconds and try again
- Contact IT support

## 👥 5 Different Roles

### 1️⃣ Front Desk Staff
**What you do:** Register patients, manage queue, process payments

**Your screens:**
- **Dashboard** → Overview of patients and payments
- **Register Patient** → New patient form
- **Patient Queue** → Patients waiting for doctor
- **Payment Checkout** → Process payments
- **Discharge** → Mark patient as done

**Daily workflow:**
```
Morning: Register new patients
Mid-day: Move patients to consultation queue
Afternoon: Process payments and discharge
```

### 2️⃣ Doctor
**What you do:** Consult patients, diagnose, prescribe, order tests

**Your screens:**
- **Dashboard** → Patient queue
- **Consultation** → Examine patient, take notes
- **Diagnosis** → Record diagnosis
- **Prescription** → Create medication list
- **Lab Orders** → Request tests
- **Nursing Tasks** → Assign nursing care

**Daily workflow:**
```
Check queue → Start consultation → Diagnose → Prescribe/Order Tests → Move to next patient
```

### 3️⃣ Nurse
**What you do:** Record vital signs, perform nursing care

**Your screens:**
- **Dashboard** → Assigned patients
- **Patient List** → All patients needing care
- **Record Vitals** → Temperature, Blood Pressure, etc.
- **Nursing Actions** → Mark care tasks complete

**Daily workflow:**
```
Check dashboard → Find patient → Record vitals → Mark tasks complete → Repeat
```

### 4️⃣ Lab Technician
**What you do:** Perform tests, upload results

**Your screens:**
- **Dashboard** → Pending tests
- **Test Queue** → List of tests to perform
- **Upload Results** → Submit test results
- **Completed Tests** → View past results

**Daily workflow:**
```
Check tests → Perform test → Upload results → Mark complete → Repeat
```

### 5️⃣ Pharmacist
**What you do:** Dispense medications to patients

**Your screens:**
- **Dashboard** → Pending prescriptions
- **Prescription Queue** → List of prescriptions
- **Dispense Medication** → Give drugs to patient
- **Dispensed History** → View past dispensing

**Daily workflow:**
```
Check prescriptions → Gather drugs → Verify → Dispense → Repeat
```

## 📋 FRONT DESK - Detailed Steps

### Register a New Patient

```
1. Click "Register Patient" button
2. Fill in form:
   - Name (required)
   - Email (required)
   - Phone number
   - Gender
   - Date of Birth
   - Blood Group
   - Medical History
   - Allergies
   - Emergency Contact
3. Click "Submit"
4. Patient added to system
```

**Tips:**
- Use YYYY-MM-DD format for dates
- Double-check email before submitting
- Get emergency contact info before registering

### Move Patient to Queue

```
1. Find patient in "Registered Patients" list
2. Click patient card
3. Click "Move to Queue" button
4. Patient moves to "Awaiting Consultation"
```

**Tips:**
- Only move when patient has checked in
- Check patient list regularly
- Move patients in order they arrive

### Process Payment

```
1. Click "Payment Checkout"
2. Select patient from dropdown
3. Enter payment amount
4. Select payment method (Cash/Card/Insurance)
5. Click "Process Payment"
6. Print receipt if printer available
```

**Tips:**
- Verify amount with doctor before charging
- Get payment before patient leaves
- Offer receipt to patient

### Discharge Patient

```
1. Click "Discharge" tab
2. Find paid patient in list
3. Click "Discharge Patient"
4. Confirm discharge
5. Patient marked as "Discharged"
```

**Tips:**
- Only discharge after payment received
- Give discharge summary to patient
- Answer patient questions
- Mark appointment follow-up if needed

## 👨‍⚕️ DOCTOR - Detailed Steps

### View Patient Queue

```
1. Click "Dashboard"
2. See all patients waiting for you
3. Patients sorted by arrival time
4. Click patient card to consult
```

**Tips:**
- See patients in queue order
- If no patients, take a break
- Patients waiting longest appear first

### Start Consultation

```
1. Click patient card in queue
2. Patient info appears (name, age, allergies)
3. Click "Start Consultation"
4. You see patient history (if any)
```

**Tips:**
- Check allergies before prescribing
- Review previous visits if available
- Ask patient about symptoms

### Record Consultation

```
1. Interview patient
2. Ask about:
   - Main complaint
   - Duration of symptoms
   - Previous illnesses
   - Current medications
3. Record in form:
   - Symptoms
   - Diagnosis
   - Notes/Observations
4. Click "Save Consultation"
```

**Tips:**
- Take detailed notes
- Write legibly (handwriting captured)
- Record any tests needed

### Create Prescription

```
1. While in consultation
2. Click "Add Medication"
3. For each medication, enter:
   - Drug name
   - Dosage (e.g., 500mg)
   - Frequency (e.g., 3x daily)
   - Duration (e.g., 7 days)
   - Instructions
4. Click "Add Prescription"
```

**Tips:**
- Double-check spelling
- Check patient allergies
- Use standard dosages
- Clear instructions for patient

### Order Lab Test

```
1. While in consultation
2. Click "Order Lab Test"
3. Select test type:
   - Blood Test
   - Urine Test
   - X-Ray
   - Ultrasound
   - ECG
   - Other
4. Add notes (if needed)
5. Click "Order Test"
```

**Tips:**
- Only order needed tests
- Check if patient already had similar test
- Explain test to patient

### Assign Nursing Care

```
1. While in consultation
2. Click "Assign Nursing Task"
3. Select task type:
   - Monitor Vital Signs
   - Wound Care
   - IV Setup
   - Medication Admin
   - Other
4. Add notes
5. Click "Assign"
```

**Tips:**
- Be specific in instructions
- Note any precautions
- Check if tasks are done later

### Complete Consultation

```
1. Finish recording all info
2. Click "Complete Consultation"
3. Patient moves to:
   - Nursing queue (if nursing needed)
   - Lab queue (if test needed)
   - Pharmacy queue (if medication only)
```

**Tips:**
- Don't leave fields blank
- Review before completing
- Patient must see results

## 💉 NURSE - Detailed Steps

### View Your Tasks

```
1. Click "Dashboard"
2. See patients assigned to you
3. See which tasks need doing
4. Click patient to see details
```

**Tips:**
- Check dashboard every hour
- Prioritize urgent tasks
- Mark tasks complete when done

### Record Vital Signs

```
1. Find patient
2. Click "Record Vitals"
3. Measure and enter:
   - Temperature (36-37.5°C is normal)
   - Blood Pressure (e.g., 120/80 mmHg)
   - Pulse/Heart Rate (60-100 bpm normal)
   - Respiratory Rate (12-20 breaths/min)
   - Oxygen Saturation (95-100% normal)
4. Optional:
   - Weight
   - Height
   - General Condition (Good/Fair/Poor)
   - Notes
5. Click "Save Vitals"
```

**Tips:**
- Record same time daily if possible
- Check normal ranges (shown in system)
- Alert doctor if abnormal
- Be gentle with patient

### Perform Nursing Action

```
1. Find task in list
2. Click task details
3. Perform the action
   (wound care, medication, etc.)
4. Click "Complete Task"
5. Add notes about what was done
6. Click "Confirm"
```

**Tips:**
- Follow doctor's instructions exactly
- Note any issues or changes
- Wash hands before/after
- Use standard precautions

## 🧪 LAB TECHNICIAN - Detailed Steps

### Check Your Tests

```
1. Click "Dashboard"
2. See pending tests
3. Tests sorted by patient name
4. Click test to see details
```

**Tips:**
- Check dashboard regularly
- Note any special instructions
- Prioritize urgent patients

### Perform Lab Test

```
1. Get patient ID from test
2. Collect sample:
   - Blood: Use correct tube
   - Urine: Sterile container
   - Other: Follow protocol
3. Label sample with patient ID
4. Perform test per protocol
5. Record results
```

**Tips:**
- Follow safety protocols
- Label everything
- Discard safely
- Double-check results

### Upload Test Results

```
1. Find test in "Pending Results"
2. Click "Upload Results"
3. Enter:
   - Test results (numbers/description)
   - Normal range (e.g., 4-11)
   - Interpretation (Normal/Abnormal)
   - Clinical notes (if needed)
   - Attach file (PDF report if any)
4. Click "Submit"
5. Doctor sees results immediately
```

**Tips:**
- Be accurate with numbers
- Include units (mg/dL, etc.)
- Note any issues (hemolyzed, etc.)
- Patient status updates automatically

## 💊 PHARMACIST - Detailed Steps

### Check Your Queue

```
1. Click "Dashboard"
2. See pending prescriptions
3. Prescriptions sorted by patient
4. Click prescription to see details
```

**Tips:**
- Check dashboard regularly
- Note any special requests
- Check drug availability

### Verify Prescription

```
1. Open prescription
2. Check:
   - Patient name matches label
   - Dosages are reasonable
   - No drug interactions
   - Patient not allergic
3. If issue, contact doctor first
```

**Tips:**
- Never dispense without verifying
- Use drug interaction checker
- Check allergies carefully
- Contact doctor if unsure

### Gather Medications

```
1. Get each drug from shelf
2. Check:
   - Drug name matches
   - Expiry date (not expired)
   - Quantity correct
   - Tablet/capsule count
3. Put in organized tray
```

**Tips:**
- Organize by dose/frequency
- Double-check everything
- Check expiry dates
- Use correct strength/form

### Dispense to Patient

```
1. Call patient to counter
2. Verify patient name and ID
3. Show each medication:
   - "This is [drug name]"
   - "Take [frequency]"
   - "For [duration]"
4. Explain side effects
5. Provide patient instructions
6. Click "Dispense" in system
7. Give receipt
```

**Tips:**
- Speak clearly
- Use patient language (not medical)
- Give written instructions
- Answer patient questions
- Patient status updates automatically

## 📊 PATIENT STATUS TRACKING

Understand patient journey:

```
Registered
  ↓ (Front Desk moves to queue)
Awaiting Consultation
  ↓ (Patient sees doctor)
Under Consultation
  ↓ (Doctor diagnoses, creates prescriptions/tests/nursing)
May go to one or more:
  → Nursing (Nurse records vitals)
  → Lab (Tech performs/uploads results)
  → Pharmacy (Pharmacist dispenses)
  ↓
Awaiting Payment
  ↓ (Front Desk processes payment)
Discharged
```

## ⏰ Daily Schedule

### Morning (8 AM - 12 PM)
```
Front Desk: Register new patients, check queue
Doctor: See patients in queue
Nurse: Record vitals for admitted patients
Lab: Process samples from yesterday
Pharmacist: Dispense morning medications
```

### Afternoon (12 PM - 5 PM)
```
Front Desk: Continue registrations, process payments
Doctor: See any remaining patients
Nurse: Check on patients, record afternoon vitals
Lab: Process samples from morning
Pharmacist: Dispense afternoon medications
```

### Evening (5 PM onwards)
```
Front Desk: Final payments, end-of-day reports
Doctor: Review notes, prepare next day
Nurse: Evening vitals, hand-off report
Lab: Clean equipment, prepare for next day
Pharmacist: Count stock, prepare for next day
```

## 🆘 Common Questions

### Q: What if I make a mistake?
**A:** Don't delete. Tell your supervisor immediately. System tracks all changes (audit log). Corrections are made with note.

### Q: How do I know what to do next?
**A:** System shows "Next Steps" for every patient. Follow those. If unclear, ask supervisor.

### Q: What if patient is in wrong status?
**A:** Report to IT support. Don't force status change yourself.

### Q: How do I access old patient records?
**A:** Click "Patient Search" → Type name → See history.

### Q: Can I change something after submitting?
**A:** No. System is locked after submit. Contact supervisor to modify.

### Q: What if system is slow?
**A:** Try refreshing page. If still slow, contact IT support.

### Q: Can I access patient data outside hospital?
**A:** No. System only works on hospital network. For security.

### Q: What's my password if I forgot?
**A:** Contact IT support. They can reset.

### Q: How long does patient stay in system?
**A:** Forever. Can search old records anytime.

### Q: Who sees my patient data?
**A:** Only staff involved in care + admin. HIPAA-protected.
